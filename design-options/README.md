# System69 Manager — design concepts

Open `system69-concepts.html` to compare three original logo and theme directions. Choose a card, then switch between Applications and Node.js runtimes. Search and selection work locally. All actions are simulations and all inventory values are sample data.

- **Signal:** cool light surfaces, cobalt accent, offset S/arrow mark. Recommended for a compact Windows utility and the existing preference for soft blue selection.
- **Foundry:** warm light surfaces, copper accent, assembled block mark, Georgia display headings with Segoe UI controls.
- **Orbit:** dark ink surfaces, mint accent, orbit/node mark, rounded geometry.

Each folder contains an editable SVG logo and theme tokens. The app name remains System69 Manager across all three choices.

Shared navigation: Applications, Node.js runtimes, PATH, Packages, Queue & activity. Uninstall review, hidden applications, silent-mode support, source ownership, and explicit PATH priority carry forward from the reference projects.

This is a design selection deliverable, not the merged functional application. No apps, packages, or PATH entries are changed.
